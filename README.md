# Hoodz-Customs

ARI is a lightweight automotive repair invoice app for generating repair invoices in the browser.

## Features

- Create an Automotive Repair Invoice (ARI) with shop, customer, vehicle, and repair details
- Add labor, parts, and fee line items with automatic subtotal, tax, and total calculations
- Generate a printable invoice preview directly in the browser

## Run locally

1. Open a terminal in the project root
2. Start a local server:

   ```bash
   npm start
   ```

3. Open `http://localhost:8000`

## Validate

```bash
npm test
```
