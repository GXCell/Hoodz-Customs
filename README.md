# Hoodz Customs

Hoodz Customs is a simple static website concept for an AI mechanic experience. The page lets a customer describe a vehicle issue, review a likely diagnosis and estimated price range, and unlock a booking flow for a service visit.

## Project files

- `index.html` – page structure and content
- `styles.css` – layout, colors, and responsive styling
- `script.js` – diagnosis logic and booking interactions

## Features

- Guided vehicle issue intake form
- Instant diagnosis summary based on selected symptoms
- Estimated repair pricing and service timeline
- Appointment slot updates based on urgency
- Booking confirmation after diagnosis is completed

## Run locally

Because this is a static site, no build step is required.

1. Open `/home/runner/work/Hoodz-Customs/Hoodz-Customs/index.html` in a browser, or
2. Serve the folder with any basic static server
